# docs/ai-coe/

Committed fork documentation: durable reference material a fresh clone needs.

- `playbooks/` - how to make each kind of change (`Contribution-and-Change-Patterns.md`).

Strategy, decisions, evaluations, and raw reference material that a future maintainer would not need to change the code correctly live outside git, in the companion workspace: `../../ai-coe-plugin-workspace/`. Start there with `00-INDEX.md` if you're orienting on the fork as a whole rather than a specific file.
